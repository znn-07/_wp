## 摘要
### 01.基礎數字判斷 (if/else)
寫一個函式判斷數字是正數、負數或零。
### 02.乘法表列印 (for loop)
使用 for 迴圈印出 2 的乘法表（2x1 到 2x10）。
### 03.倒數計時器 (while loop)
使用 while 迴圈從 5 倒數到 1，最後印出 "Blast off!"。
### 04.陣列總和計算 (array + for)
寫一個函式傳入數字陣列，回傳所有數字的總和。
### 05.物件屬性讀取 (object)
建立一個 user 物件，包含姓名與年齡，並寫一個函式印出自我介紹。
### 06.尋找陣列最大值 (array + if)
寫一個函式找出陣列中的最大數字。
### 07.JSON 格式轉換 (JSON)
將一個 JavaScript 物件轉為 JSON 字串，再轉回物件。
### 08.篩選陣列資料 (array + function)
寫一個函式，從陣列中篩選出大於 10 的數字。
### 09.處理 JSON 物件陣列 (object + array + for)
有一組學生資料，請印出所有及格（>=60）學生的姓名。
### 10.簡易購物車計算 (advanced object)
計算購物車內物品的總價。
